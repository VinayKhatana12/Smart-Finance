# Android (Capacitor) build instructions

The Android project lives in `client/android` (generated by `npx cap add android`).
The backend and web app are untouched; the app talks to the deployed HTTPS API.

## One-time machine setup

1. JDK 17+ (Java 23 works).
2. Android SDK — install via Android Studio, or the command line:

   ```bash
   mkdir -p C:/Android/Sdk/cmdline-tools && cd C:/Android/Sdk/cmdline-tools
   curl -L -o tools.zip https://dl.google.com/android/repository/commandlinetools-win-11076708_latest.zip
   unzip tools.zip && mv cmdline-tools latest
   sdkmanager --licenses && sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
   ```

3. `client/android/local.properties` → `sdk.dir=C:/Android/Sdk`
4. Signing: `client/android/keystore.properties` (gitignored) with
   `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. A demo keystore is
   at `%USERPROFILE%/smart-finance-release.keystore`
   (store/key password `smart-finance-demo`, alias `smart-finance`) — replace it
   before any public distribution.

## Build commands (from `client/`)

```bash
# 1. Build the React frontend for the Android shell
#    .env.capacitor must set VITE_API_URL=https://<your-deployed-https-backend>
npm run build:android

# 2. Sync web assets + plugins into the Android project
npx cap sync android

# 3. (Already done once) add the platform
# npx cap add android

# 4. Open Android Studio (optional GUI path)
npx cap open android

# 5. Debug APK (auto-signed with the debug key)
cd android && gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk

# 6. Signed release APK
cd android && gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk

# 7. Signed AAB for Play Store distribution
cd android && gradlew bundleRelease
# → app/build/outputs/bundle/release/app-release.aab
```

Gradle 8.13+ is required by AGP; if the wrapper download fails, install Gradle
directly and run its `gradle.bat` instead of `gradlew`.

## Backend configuration for the Android client

- Deploy the API behind HTTPS and set `VITE_API_URL` to that URL in
  `.env.capacitor` before building. A clear-text URL is rejected in release
  builds (the app warns at startup if it is not HTTPS).
- On the deployed backend, set:
  - `CLIENT_ORIGIN` to include `https://localhost` (the Capacitor WebView origin)
  - `COOKIE_SAMESITE=none` — the Android WebView is a different site, so the
    auth cookies need SameSite=None over HTTPS to round-trip.
- The app treats a 401 as "session expired": it silently renews via the refresh
  cookie, and only prompts for sign-in when that fails.
